# en-agent 0.2.0 для Windows x64

При запуске en-agent проверяет обновления приложения и скиллов. Кнопка **Проверить обновления** повторяет обе проверки и показывает результат для каждого компонента. Подготовленное обновление приложения применяется при следующем запуске.

Скиллы скачиваются отдельно. При первой установке нужен интернет. Если совместимые скиллы уже скачаны, launcher использует их и при работе офлайн. OpenCode обновлён до 2.4.2.

**Если у вас установлена 0.1.0**, завершите en-agent, скачайте `en-agent-0.2.0-windows-x64-setup.exe` из этого релиза и запустите его с выбором прежней папки установки. Чаты, настройки и скачанные скиллы сохранятся. Это разовый переход. Последующие версии приложение получит через встроенную проверку.

Для новой установки используйте тот же EXE. Для переносимой установки распакуйте `en-agent-0.2.0-windows-x64.zip` целиком в отдельную папку и запустите `en-agent.exe`. Рядом с каждым файлом опубликована его контрольная сумма SHA-256.
