# en-agent 0.0.4

Совместимое PATCH-исправление установщика; sequence 110.

Установщик автоматически находит существующую EXE-установку, включая 0.0.1, и обновляет её в той же папке. Больше не предлагает перенос из ZIP при обычной установке. Если сведения о версии потеряны, восстанавливает приложение по зарегистрированному пути или в стандартной папке, сохраняя существующие данные. Переименовывать или удалять старую папку не нужно.

Сохраняются чаты, настройки, данные аккаунтов и файлы игр. Перед сменой версии создаётся резервная копия данных; прежний комплект остаётся для возврата при неудачном запуске. Повторный запуск установщика не сбрасывает этот резерв. Установка требует закрыть en-agent и не позволяет понизить более новую установленную версию.

Launcher 0.0.4; OpenCode 2.3.0; en-skills 0.0.2; MCP runtime 0.0.1. Форматы хранения не меняются.

Проверены 38 тестов launcher, обновление установленного EXE-пакета 0.0.1 без ручного указания пути, повторная установка, восстановление потерянного state.json и регистрационных сведений, сохранность данных и резервной копии.
