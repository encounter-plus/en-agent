# en-agent 0.0.2

Совместимое PATCH-обновление launcher и комплекта; sequence 104.

- При ошибке «Не удалось запустить комплект» launcher показывает причину, этап и путь к локальному логу. Лог сохраняет цепочку исключений и место сбоя, дополняется при повторных ошибках и использует временную папку, если папка установки недоступна для записи.
- В комплект включён en-skills 0.0.2 (коммит `0e15004`): уточнены правила редактирования существующих игр, проверки оформления и работы с изображениями.
- MCP runtime остаётся 0.0.1, OpenCode — 2.0.32. Форматы хранения и настройки не меняются.

Лог launcher передаётся отдельно от экспорта диагностики и может содержать локальные пути и текст системных ошибок. Это улучшение диагностики; причина исходного сбоя повторного запуска на компьютере пользователя пока не установлена.

Проверки перед выпуском: 33 теста launcher, 354 теста en-skills, 99 тестов runtime и MCP smoke (36 инструментов); проверка npm-пакета и ссылок 12 скиллов; PowerShell-проверки логирования и выбора браузера. Собранный EXE дважды запущен и штатно завершён с тремя подключёнными MCP. Проверены память игры, импорт синтетической игры с реальной моделью, браузерное превью на широком и узком экранах, целостность чистой распаковки ZIP, тестовая установка и удаление с сохранением данных. Локальное подписанное обновление 0.0.1 → 0.0.2 сохраняет синтетические данные и настройки.
