# en-agent 0.0.3

Подготовлено в исходниках и собрано в локальный комплект `0.0.3-local.20261116.2` (sequence 106); stable-выпуск не опубликован.

Исправлено неполное автоопределение браузеров Windows: добавлен Яндекс Браузер из стандартных каталогов пользователя и Program Files. Он доступен для явного выбора, использует отдельный профиль агента и отображается в диагностике. Сохраняется порядок автоматического выбора Chrome → Edge → Яндекс → браузеры Playwright. Изменение согласовано как PATCH.

Версия launcher — 0.0.3. Включены en-skills 0.0.2 и MCP runtime 0.0.1. README направляет на последний опубликованный выпуск независимо от версии исходников.

OpenCode обновлён с 2.0.32 до 2.3.0. Версия закреплена в `config/opencode.json`; сборщик отклоняет другой бинарник. Проверены API, pairing/GUI, три MCP, память игры, синтетический импорт с реальной моделью big-pickle, повторный запуск Windows EXE и переход с 0.0.2 с сохранением реальной сессии OpenCode, настроек и данных. Самостоятельное обновление OpenCode выключено; правило AGENTS.md требует проверки доступных обновлений перед выпуском или запрошенным push, если предыдущая проверка старше 14 дней.

Кнопка «Отправить журнал» собирает структурированную диагностику и журналы launcher в отдельную временную папку и открывает её в Проводнике. При ошибке до открытия главного окна папку можно открыть из сообщения об ошибке. История чатов, игры и данные аккаунтов не включаются; файлы автоматически никуда не отправляются. Это доработка диагностики в согласованном PATCH 0.0.3.

Проверены синтетическое обнаружение Яндекса, настройки запуска и сохранение выбора в Windows-форме. Браузерное превью проверено через доступный Chromium-браузер; реальный запуск Яндекса остаётся непроверенным, поскольку он отсутствует на проверочной машине.
