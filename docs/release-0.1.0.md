# en-agent 0.1.0

Подготовка выпуска; публикация и установка выполняются отдельно.

## Состав

- Launcher: 0.1.0.
- en-skills: 0.1.0, исходный коммит `8c3acd5` — совместная подготовка игры в Google-документе.
- Encounter MCP runtime: 0.0.1.
- OpenCode: 2.3.0.

## Изменения

Скиллы хранятся отдельно от файлов приложения. Команда «Обнови en-skills» проверяет официальный стабильный выпуск, контрольную сумму и содержимое архива. После успешного обновления нужно закрыть en-agent, запустить его снова и открыть новый чат.

При обновлении приложения встроенные скиллы заменяют активный набор только при большей или равной версии. Более новая независимо установленная версия сохраняется. Обновление скиллов не заменяет MCP runtime.

Публикация скиллов, резервное копирование и откат используют общую блокировку. Аварийное завершение MCP отменяет загрузку; временная распаковка не попадает в резервную копию. Занятая блокировка сохраняет подготовленное обновление приложения для следующего запуска. Поддержаны пути с типографскими апострофами.

## Проверки и выпуск

Автоматические тесты покрывают сравнение версий, проверку архивов, прерывание обновления, блокировки, согласованность снимка и откат. Синтетический сценарий в настоящем OpenCode проверяет вызов обновления, перезапуск и чтение нового поколения скиллов.

Проверки подготовки 2026-11-18: en-agent — 58 тестов; `en-skills check` — 354 теста и проверки скиллов, каталога и eval-наборов; установка npm-пакета в чистый consumer — успешно; runtime validate — 99 тестов и MCP smoke с 36 инструментами. Локальный комплект `0.1.0-local.20261118.4`, sequence 118, прошёл проверку манифеста и файлов, а также синтетический сценарий обновления в OpenCode.

Перед stable-публикацией пройти [порядок выпуска](releases.md): назначить новый ID и sequence по актуальному каналу, проверить подписанный Windows-комплект и установку. Проверка с внешней моделью в предыдущем прогоне была ограничена HTTP 429 провайдера; синтетическая модель не заменяет эту проверку.
