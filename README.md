# en-agent

Приложение для Windows, которое помогает автору подготовить игру Encounter — от замысла и сценария до проверки кодов и переноса согласованных материалов в движок. Вы общаетесь с AI-ассистентом в чате, а он использует встроенные [en-skills](https://github.com/encounter-plus/en-skills) и инструменты работы с файлами, Encounter и браузером.

Для каждой игры выбирается своя папка: в ней остаются сценарий, исходные материалы, решения и список задач. Можно вернуться к работе в новом чате. Git и программирование для подготовки игры не нужны.

## Установка на Windows — без сборки

Первый выпуск — **0.0.1**. Готовые файлы доступны в [GitHub Release 0.0.1](https://github.com/encounter-plus/en-agent/releases/tag/0.0.1): EXE-установщик и переносимый ZIP для Windows x64.

### Способ 1: установщик — обычная установка

1. Откройте [релиз 0.0.1](https://github.com/encounter-plus/en-agent/releases/tag/0.0.1) и раскройте список **Assets** (файлы выпуска), если он свёрнут.
2. Скачайте **en-agent-0.0.1-windows-x64-setup.exe**. Это установщик; распаковывать его не нужно.
3. Откройте папку **Загрузки** и дважды нажмите скачанный EXE. Подтвердите установку для текущего пользователя.
4. При вопросе о переносе старой ZIP-установки выберите **Нет**, если запускаете приложение впервые. Если переносите существующую установку, сначала завершите её работу и выберите её папку: исходная папка сохранится.
5. После установки откройте меню **Пуск**, найдите **en-agent** и запустите его.

### Способ 2: ZIP — запуск из выбранной папки

1. На той же странице скачайте **en-agent-0.0.1-windows-x64.zip**.
2. В папке **Загрузки** нажмите по ZIP правой кнопкой и выберите **Извлечь всё**.
3. Укажите постоянную папку, например `C:\Users\ВашеИмя\Apps\en-agent`, и нажмите **Извлечь**. Не выбирайте защищённую папку Program Files.
4. Откройте извлечённую папку и дважды нажмите **en-agent.exe**. Не запускайте его внутри архива и не переносите отдельно от остальных файлов.

Файлы **.sha256** содержат контрольные суммы для проверки загрузки; их не запускают. **Source code (zip/tar.gz)** — исходники для разработчиков, для установки они не подходят. Достаточно выбрать один способ выше. Node, Git и OpenCode уже входят в комплект; открывать терминал и собирать программу не нужно. Права администратора не требуются.

### Первый запуск

1. В окне en-agent выберите браузер агента: можно оставить **Автоматически**. Должен быть установлен Chrome или Edge.
2. Создайте обычную пустую папку для новой игры, выберите её и введите название игры. Для продолжения работы выберите папку существующей игры.
3. Дождитесь открытия чата **OpenCode** в браузере. Игра появится в **Projects**. Небольшое окно en-agent оставьте открытым.
4. Подключите модель по шагам ниже. Затем напишите в чат: **«Помоги создать игру через game-author»**.
5. Подключайте Encounter, когда понадобится читать или изменять игру в движке. Поиск Exa настраивается отдельно, когда нужен поиск источников в интернете.

### Какие данные вводить и куда

| Для чего | Что понадобится | Куда вводить |
| --- | --- | --- |
| Общение с AI-моделью | API-ключ выбранного провайдера модели или предложенный им вход в аккаунт | В браузерном окне **OpenCode**, раздел **Providers** |
| Работа с игрой Encounter | Ваш логин и пароль **Encounter** | В окне en-agent нажать **Аккаунт Encounter** |
| Поиск источников Exa | **API-ключ Exa** из его кабинета | В окне en-agent нажать **Поиск Exa** |

Не вставляйте пароли и ключи обычным сообщением в чат. Это три разных подключения: ключ Exa не заменяет ключ модели, а пароль Encounter не подходит для Exa.

### Подключить AI-модель

1. В открывшемся OpenCode откройте **Providers** (провайдеры) и нажмите **Connect Provider** (подключить провайдера).
2. Выберите сервис, которым будете пользоваться. Провайдер — компания, предоставляющая модель; её доступность и оплата определяются этим сервисом.
3. Если выбран вход через **API key**, создайте API-ключ в личном кабинете именно этого сервиса, скопируйте его и вставьте в поле ключа OpenCode. Если сервис предлагает вход через аккаунт, следуйте его окну авторизации.
4. Для подключения по API-ключу нажмите **Test connection**, если эта кнопка доступна, затем **Save**. Вернитесь к чату игры и выберите модель подключённого провайдера в списке моделей.
5. Отправьте первый запрос. Если сервис сообщает об отсутствии кредита или доступа, проверьте его кабинет. Подписка на отдельный чат и доступ к API могут оплачиваться по-разному.

[Официальная инструкция подключения провайдера в OpenCode](https://github.com/anomalyco/opencode/blob/v2.0.32/services/www/src/docs/content/console/providers.mdx).

### Подключить аккаунт Encounter

1. Вернитесь в небольшое окно en-agent и нажмите **Аккаунт Encounter**.
2. В поле **Логин** введите логин вашего аккаунта Encounter, в поле **Пароль** — пароль этого аккаунта.
3. Нажмите **Сохранить аккаунт** и дождитесь сообщения **Аккаунт сохранён**. Пароль хранится в системном хранилище Windows.
4. Вернитесь в чат и сообщите ссылку на игру или её домен и номер. Эти данные можно передавать в чате; пароль — нельзя.
5. Если для входа открылось окно браузера агента, завершите вход или CAPTCHA в нём. Пока домен игры не известен, приложение только сохраняет аккаунт, без проверки входа.

### Подключить поиск Exa

1. В окне en-agent нажмите **Поиск Exa**, затем **Открыть кабинет Exa — регистрация и API Keys**.
2. На сайте Exa зарегистрируйтесь или войдите в свой аккаунт. Логин и пароль Exa вводятся **на сайте Exa**, не в en-agent.
3. В разделе **API Keys** создайте ключ и скопируйте его. Вернитесь в окно **Поиск Exa** и вставьте ключ в поле **API-ключ**.
4. Нажмите **Проверить**. Если проверка успешна, нажмите **Сохранить / заменить**: проверка сама по себе ключ не сохраняет.
5. Нажмите **Применить и перезапустить**, подтвердив перезапуск после завершения текущей работы. Либо закройте en-agent и запустите его заново.
6. В чате попросите: **«Найди источники об истории обсерватории и дай ссылки»**. Поисковые запросы, включая проверочный, расходуют лимит вашего аккаунта Exa.

Нужны Windows 10/11 **x64**, интернет и установленный Chrome или Edge. Нужны Windows PowerShell и .NET Framework 4.8. Нативные EXE launcher и установщик не используют VBS/Windows Script Host. Локальная сборка пока без доверенной Authenticode-подписи: нужен сертификат сопровождающего. Если Windows пометила скачанный архив как заблокированный, проверьте источник, откройте **Свойства ZIP → Разблокировать** (если пункт есть) и распакуйте заново. Если запуск скриптов запрещён политикой организации, обратитесь к администратору; не отключайте защиту системы.

Для повторного запуска используйте тот же **en-agent.exe**; можно создать на него ярлык. Для выхода нажмите **Завершить работу** в launcher. Закрытие вкладки браузера не останавливает агент.

Не удаляйте папку установки: в `data/` находятся настройки и чаты, а игры — в выбранных вами папках. Launcher проверяет подписанные обновления из отдельного репозитория [en-agent-updates](https://github.com/encounter-plus/en-agent-updates) и применяет их при следующем запуске. Технические файлы оттуда вручную скачивать не нужно: установщик и ZIP всегда находятся в [Releases en-agent](https://github.com/encounter-plus/en-agent/releases). Распаковывать новые версии поверх работающей установки не нужно. Пароли Encounter хранятся в Windows Credential Manager и не переносятся вместе с ZIP.

## Как устроен интерфейс

После запуска вы работаете с тремя окнами:

| Окно | Для чего оно |
| --- | --- |
| **en-agent** — небольшое окно запуска | Выбрать настройки, подключить Encounter, увидеть состояние подключения и завершить работу |
| **OpenCode** — чат в браузере | Выбрать провайдера и модель, открыть проект игры в **Projects**, общаться с ассистентом и отвечать на его вопросы |
| **Браузер агента** — отдельное окно | Просматривать страницы и превью, работать с Google Docs/Sheets, при необходимости завершить вход вручную |

Браузер агента использует отдельный профиль. Вход в Google в вашем обычном браузере не означает, что агент тоже вошёл. Чат открывается в системном браузере по умолчанию; это может быть другой браузер.

Кнопки окна en-agent:

| Кнопка | Что делает |
| --- | --- |
| **Аккаунт Encounter** | Сохранить логин и пароль или забыть аккаунт. Пароль вводится в отдельном окне, не в чате |
| **Поиск Exa** | Инструкция регистрации, сохранение, проверка и замена ключа поиска |
| **Настройки** | Посмотреть версию и подготовленное обновление, сменить браузер агента с перезапуском |
| **Журнал** | Открыть события запуска и подключений |
| **Экспорт диагностики** | Сохранить `diagnostic-export.json` в папке установки для разбора ошибки |
| **Повторить запуск** | Повторить запуск после ошибки; не повторяет запись в игру |
| **Завершить работу** | Остановить локальный сервер и связанные процессы |

## Первая игра и ежедневная работа

1. Запустите `en-agent.exe` или установленный ярлык и выберите папку игры. Для новой игры используйте пустую папку.
2. В чате OpenCode подключите доступного вам провайдера и выберите модель. Условия доступа, лимиты и стоимость зависят от провайдера; ключ модели не является паролем Encounter.
3. Напишите, например: **«Используй game-author. Готовим ночную Схватку на 10 уровней. Помоги составить план»**.
4. Передайте сценарий, фотографии или ссылки и уточните задачу: **«Проверь сценарий через game-audit»**, **«Сверь фото кодов через check-code-photos»**. [Все скиллы и примеры запросов](https://github.com/encounter-plus/en-skills#какие-скиллы-есть).
5. Для работы с движком подключите аккаунт кнопкой **Аккаунт Encounter**, затем сообщите агенту домен и игру. Для подготовки текста подключение не требуется.
6. Перед изменениями в Encounter или Google проверьте предложенные правки и согласуйте их. Для закрытого Google-документа войдите в аккаунт в браузере агента; отдельного Google API key не требуется.
7. Закончив, нажмите **Завершить работу**. В следующий раз выберите ту же папку игры.

Материалы и переносимая память находятся в папке игры (`GAME.md`, `decisions.md`, `tasks.md`, `sources/`, `levels/`, `artifacts/`), а чаты и настройки — в `data/` установки. Сохраняйте обе папки. Пароли Encounter хранятся отдельно в Windows Credential Manager.

## Как подключить поиск: ключ EXA

В окне en-agent нажмите **«Поиск Exa»**. В этом же окне есть инструкция и ссылка на [кабинет Exa](https://dashboard.exa.ai/api-keys): зарегистрируйтесь или войдите, создайте API-ключ и вставьте его в поле.

- **Проверить** — выполнить один поисковый запрос с введённым ключом. Если поле пустое, проверяется сохранённый ключ или `EXA_API_KEY` из окружения. Проверка расходует лимит по тарифу Exa и сама не сохраняет ключ.
- **Сохранить / заменить** — сохранить введённый ключ в Windows Credential Manager для этой установки. Чтобы заменить ключ, введите новый и нажмите ту же кнопку.
- **Удалить ключ** — удалить сохранённый ключ. Переменная Windows `EXA_API_KEY`, если задана, остаётся доступной.
- **Применить и перезапустить** — после сохранения или удаления перезапустить OpenCode и браузер агента с подтверждением. Сначала завершите текущую работу. Можно вместо этого закрыть en-agent и запустить его позже.

Exa нужен для поиска источников в интернете. Это отдельный аккаунт и ключ, не ключ модели и не пароль Encounter. Сохранённый ключ не показывается в поле, не записывается в папку игры или журналы и имеет приоритет над переменной `EXA_API_KEY`. Лимиты и баланс проверяются в кабинете Exa.

Альтернативный способ: создайте пользовательскую переменную Windows `EXA_API_KEY` через **«Изменение переменных среды текущего пользователя»**, затем выйдите из учётной записи Windows и войдите снова перед запуском через ярлык. Для ключа, сохранённого через GUI, выходить из Windows не нужно.

Проверочный запрос в чате: **«Используй websearch: найди источники об истории обсерватории и дай ссылки»**. [Официальная инструкция Exa](https://exa.ai/docs/get-started/quickstart) · [Подробнее о поиске](docs/technical.md#поиск-exa-и-википедия).

## Если не получается запустить

Проверьте, что ZIP полностью распакован, папка доступна для записи и Chrome или Edge установлен. Посмотрите этап и ошибку в окне en-agent. После устранения причины нажмите **Повторить запуск**; для сообщения об ошибке приложите экспорт диагностики. Ошибки модели и её лимитов отображаются в чате OpenCode.
