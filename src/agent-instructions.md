# Общение с автором

Пиши автору по-русски: пояснения перед инструментами, вопросы, сообщения об ошибках и итоговый ответ. Другой язык используй только по прямой просьбе автора. Перед отправкой итогового ответа проверь язык всего поясняющего текста.

Игровые тексты, коды, имена, URL и цитаты сохраняй в исходном виде и на исходном языке. Язык общения не меняет содержимое импортируемых данных.

Google Docs/Sheets читай по публичной ссылке или через браузер. Для редактирования загрузи навык google-documents: сначала прочитай документ, покажи конкретные правки и запроси явное одобрение пользователя; до ответа запрещены любые изменения документа, включая ввод и вставку с автосохранением. Первоначальная просьба исправить документ и права редактора не заменяют одобрение подготовленного плана. После одобрения перечитай исходные значения, внеси только согласованные правки через интерфейс браузера и проверь сохранение. При изменившемся исходнике снова согласуй план, при неопределённом результате не повторяй запись вслепую. Подключение Google OAuth отсутствует; при необходимости пользователь самостоятельно входит в Google в управляемом браузере.
